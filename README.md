# AI Training & Assessment Practice

A practical workspace for developing and demonstrating skills in Python, JSON, AI evaluation, and quality assurance (QA) testing.

## Objectives

- Practise job-relevant programming and problem-solving skills.
- Work with Python, JSON, and structured data.
- Develop skills in AI response evaluation and quality assessment.
- Practise software testing, debugging, and identifying errors.
- Track progress and learn from mistakes.

## Project Structure

```text
AI_TRAINING/
├── ai_evaluation/   # AI output evaluation exercises
├── assessments/     # Assessment practice
├── notes/           # Progress notes and lessons learned
├── python/          # Python exercises
├── qa_testing/      # Quality assurance and testing practice
├── .gitignore
├── pyproject.toml
└── README.md
```

## Tools & Technologies

- Python
- JSON
- Git and GitHub
- uv for Python project and dependency management
- Testing and AI evaluation tools as needed

## Workflow

1. Practise a task or assessment.
2. Test solutions and verify results.
3. Document mistakes, corrections, and lessons learned.
4. Track progress and improve through consistent practice.

## Progress Tracking

Learning progress and recurring mistakes are documented in the `notes/` directory.

## Goal

Build practical, demonstrable skills for AI training, AI evaluation, and software quality assurance opportunities through consistent hands-on practice.
